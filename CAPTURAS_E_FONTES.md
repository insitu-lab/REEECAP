# Referências visuais reais dos fluxos de exportação

O site apresenta imagens publicadas por terceiros **diretamente de seus domínios**, com crédito e link para a página onde apareceram. Não estão incluídas no ZIP e podem deixar de carregar se os sites bloquearem hotlinking; os cartões textuais continuam utilizáveis. Referência visual não substitui o passo a passo oficial. **Não são capturas de autoria do REEECAP nem telas produzidas por IA.**

## REEECAP 2.3: carregamento sob demanda
As imagens de terceiros são carregadas apenas quando o visitante toca em **Ver captura real**. Isso faz uma solicitação ao domínio da fonte. Em caso de erro de rede, ainda há o link para a página de origem. Nenhum dado ZIP é enviado nessas requisições.
